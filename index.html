Workflow Pipeline

Reconstruction & Scale Pipeline

Automated sequence for processing 2D object photos into physically verified 3D assets.

STAGE 01

2D PHOTO INPUT

Upload object photograph or multi-view images

STAGE 02

3D MESH SYNTHESIS

Extract feature points & compute depth field

STAGE 03

SCALE CALCULATION

Compute ratio $S = \frac{L_{known}}{L_{measured}}$

STAGE 04

GEOMETRY SCALING

Apply 4x4 scale matrix transformation

STAGE 05

CALIBRATED 3D MODEL

Export physically accurate 3D OBJ model

REST API Documentation

Vision2Scale FastAPI Integration

Connect frontend client applications to high-performance Python 3D reconstruction & calibration backends.

POST
/reconstruct

Upload 2D image photo to create a 3D reconstruction job.

POST
/jobs

Create a physical length calibration job for a 3D mesh.

{ "job_id": "job-8f92a10c", "status": "processing", "known_length": 10.0, "measured_length": 5.0 }

/jobs/{job_id}/result

Retrieve completed calibration result metrics and scaled OBJ mesh file.

Backend Files Breakdown

  • main.py
    FastAPI application entry point, `/reconstruct` & `/jobs` routes, CORS setup.
  • reconstruction.py
    PyTorch/NeRF 3D reconstruction model extracting point clouds & 3D meshes from 2D images.
  • pipeline.py
    Asynchronous calibration job orchestrator and stage execution manager.
  • scale.py
    Scale factor solver ($Scale = Known / Measured$) with physical unit conversions.
  • reconstructed_mesh.obj / scaled_mesh.obj
    Reconstructed raw 3D model and final verified physically-calibrated 3D asset.

About Vision2Scale

The Vision2Scale module bridges 2D computer vision and 3D physical engineering. Reconstructing 3D objects from 2D photographs (via photogrammetry or neural implicit representation) produces scale-ambiguous 3D models. Vision2Scale takes uploaded 2D object photos, synthesizes their 3D surface mesh geometry, and calculates physical scaling ratios based on real-world reference lengths.
